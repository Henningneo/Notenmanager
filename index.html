Datenschutz

Gespeichert werden deine Fächer und Noten sowie der Name, den der Admin deinem Code gibt. Beides wird schon auf deinem Gerät mit deinem Anmeldecode verschlüsselt und nur verschlüsselt übertragen. Lesen kann es nur, wer deinen Code kennt: du und der Admin, der die Codes vergibt. Der Betreiber der Datenbank sieht nur verschlüsselte Daten. Zusätzlich liegt eine verschlüsselte Kopie im Speicher deines Browsers.

Für die Liste der letzten Anmeldungen (Optionen, Sicherheit) werden Zeitpunkt und Gerätetyp gespeichert, z. B. „Android, Chrome“, ebenfalls mit deinem Code verschlüsselt. IP-Adressen werden nicht gespeichert. Änderst du deinen Code, bleibt ein Vermerk vom alten auf den neuen Code (nur als Prüfsumme). Der neue Code wird zusätzlich so verschlüsselt hinterlegt, dass nur der Admin ihn lesen kann, damit er dein Profil weiter verwalten kann.

Die verschlüsselten Daten liegen in Google Firebase (Cloud Firestore, Rechenzentren in der EU). Die Seite wird über GitHub Pages ausgeliefert, die Firebase-Bibliotheken kommen von Google. Dabei verarbeiten GitHub und Google technisch bedingt deine IP-Adresse und Browserdaten. Die Schriftarten liegen direkt auf dieser Seite. Es gibt keine Werbung, kein Tracking und keine Weitergabe an Dritte.

Wenn deine Daten gelöscht werden sollen, wende dich an die Person, von der du deinen Code hast. Dann werden Code und Profil entfernt. Mit der Nutzung nimmst du diese Hinweise zur Kenntnis.
